คู่มือใช้ 📖

น้องครีเอทีฟทำอะไรได้บ้าง + ใช้ยังไง — อ่านครั้งเดียว ใช้เป็นเลย

💬คุยกับน้องครีเอทีฟ

พิมพ์ถามอะไรก็ได้เรื่องคอนเทนต์ — คิดแคปชัน สคริปต์ ไอเดีย แคมเปญ · เจอเทรนด์ TikTok/มีม แคปมาแปะ (📎) แล้วกด "💬 ถามน้อง" น้องดูรูปแล้วดัดให้เข้ารีสอร์ทเลย

✨คลัง Hook

คลังประโยคเปิดเด็ดๆ สำหรับรีสอร์ท · เจออันที่ชอบกด "ใช้อันนี้" น้องเขียนสคริปต์ + แคปชันจาก hook นั้นให้เลย

≈เทรนด์/โอกาส

กด "🔥 ดึงเทรนด์ล่าสุด" น้องค้นเว็บหาของฮิตตอนนี้จริงๆ + มีโอกาส/ฤดูกาลเดือนนี้ (วันแม่ หน้าฝน) · กด "ทำคอนเทนต์" น้องขยายเป็นไอเดีย+สคริปต์

🎬สตูดิโอ (ส่งคลิปให้น้องตัด)

อัปรูป/วิดีโอจริง (คลิป ≤50MB) + เขียนบอกว่าอยากได้แบบไหน (คิดไม่ออกกด 🧠 ให้น้องคิดให้) → กด ส่งให้น้องตัด · คลิปเสร็จมาโผล่ให้โหลด · ไม่ถูกใจกด 🔁 ขอแก้เพิ่ม ได้ (ฟรี)

📊วิเคราะห์โพสต์

แคปหน้า Insights (IG/FB/TikTok) มาวาง → น้องอ่านตัวเลขแล้วบอกว่า โพสต์ไหนปัง ควรทำอะไรต่อ · ไม่ต้องรอต่อ API

🎨วาดรูป (ฟรี)

ในหน้าแชท พิมพ์บอกว่าอยากได้รูปแบบไหน แล้วกดปุ่ม 🎨 น้องวาดให้ (ใช้ทำภาพ mood/ไอเดีย/แบ็กกราวด์)

🖼️แก้รูปจริง

ในหน้าแชท กดปุ่ม 📎 อัปรูปจริงของรีสอร์ท + สั่งว่าจะแก้ยังไง (เช่น เปลี่ยนท้องฟ้าตอนเย็น ใส่ข้อความ) น้องแก้ให้โดยเก็บรูปเดิมไว้

▤ข้อมูลแบรนด์

พิมพ์สิ่งที่อยากให้น้อง จำเพิ่ม — โปรเดือนนี้ ราคาใหม่ กิจกรรม · น้องอ่านทุกครั้งก่อนตอบ มีผลทันที ไม่ต้องบรีฟซ้ำ · ทุกเช้า 07:00 น้องยังทำ บรีฟเช้า รอไว้ที่หน้าหลักให้อัตโนมัติ

🎯Ads FB/IG

แคปหน้าโฆษณามาวาง → น้องแกะตัวเลขเป็น แดชบอร์ด (การ์ดสถิติ+ตารางแคมเปญ+คำแนะนำ) บอกว่า ตัวไหนคุ้ม ตัวไหนควรหยุด · จำล่าสุดไว้ให้ทั้งทีม

📅ปฏิทิน + 💾 คลังไอเดีย

วางแผนโพสต์ทั้งเดือน + เก็บแคปชัน/ไอเดียเด็ด · แชร์กันทั้งทีม ทุกคนเห็นตรงกัน

📱 ติดตั้งเป็นแอปบนมือถือ: iPhone → เปิดใน Safari → ปุ่มแชร์ → "เพิ่มลงหน้าจอโฮม" · Android → Chrome → เมนู ⋮ → "ติดตั้งแอป" — จะได้ไอคอน 🎨 กดใช้เหมือนแอปจริง ไม่ต้องจำลิงก์
💡 เคล็ดลับ: งานส่วนใหญ่เริ่มที่ "คุยกับน้อง" ได้เลย — คิดไม่ออกก็พิมพ์ถามน้องก่อน แล้วค่อยไปหน้าอื่นตามงาน · คลิปที่ตัดเสร็จรวมอยู่ที่ "คลังคลิป 🗂️"
